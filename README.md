# HealthySteps API

## Project Description

HealthySteps API is an ASP.NET Core REST API developed to support the HealthySteps Android application. The API provides user registration, secure password handling, login, user information and user settings.

## Technologies

- ASP.NET Core Web API
- .NET 8
- Entity Framework Core
- GitHub
- GitHub Actions
- xUnit
- Retrofit
- Android Studio
- Kotlin

## API Features

- User registration
- Secure password hashing
- User login
- User information retrieval
- User settings
- Database storage
- REST API endpoints

## Database

The API uses Azure SQL Database for persistent user data.

## Testing

Unit tests were created using xUnit to test password hashing and password verification.

## GitHub Actions

GitHub Actions automatically restores dependencies, builds the API and runs the automated tests.
